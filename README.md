## Program Description

This program demonstrates conditional statements, loops, functions, user input, and error handling through a simple student score checker.

## Concepts Used

- **if, else if, else:** Checks whether the score is valid and determines if the student passed or failed.
- **for loop:** Repeats the result message three times.
- **String:** Stores the result of the score evaluation.
- **Functions:** Accepts a score as a parameter and returns the result.
- **try-catch:** Handles invalid input, such as entering letters instead of numbers.
- **stdin.readLineSync():** Reads the score entered by the user.
- **int.parse():** Converts the user's input into an integer.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal in the project folder.
3. Run `dart run week8_logic_problem_set.dart`.
